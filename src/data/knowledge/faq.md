# 常见问题

## 1. EnterprisePilot 适合什么场景

EnterprisePilot 适合企业知识问答、内部信息查询、工具协作以及多步骤智能体任务场景。

## 2. 为什么需要 Trace

Trace 能帮助用户看清：

- Agent 为什么做出某个判断
- 是否调用了工具
- 工具返回了什么
- 最后为什么生成这个回答

这样更便于调试和解释。

## 3. 为什么需要评测

评测可以帮助团队衡量：

- 工具选择是否正确
- 检索结果是否命中
- 延迟是否可接受
- 回答质量是否达到要求

## 4. 什么是多工具智能体

多工具智能体指的是一个 Agent 能同时组成多个工具能力，并根据用户问题灵活选择工具组合，而不是单一回答模式。

## 5. 为什么以企业信息为主

企业场景中最关键的是：

- 数据私密性
- 结构化信息查询
- 知识库可更新
- 需要审计和可解释性

因此 RAG + 多工具智能体特别适合企业应用。
