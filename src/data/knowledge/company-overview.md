# EnterprisePilot 企业知识概览

## 1. 项目定位

EnterprisePilot 是一个面向企业知识问答场景的智能体平台，结合了大语言模型、检索增强生成（RAG）、工具调用、可观测性与多步骤 Agent 工作流。

它的目标不是单纯“回答问题”，而是帮助企业在真实场景中完成：

- 知识检索
- 工具调用
- 结构化信息提取
- 多步骤任务编排
- 可审计的执行轨迹展示

## 2. 核心能力

### 2.1 知识问答

EnterprisePilot 能对企业内部知识进行检索和回答，例如：

- 公司制度
- 产品说明
- 技术文档
- 运营流程
- 组织信息

### 2.2 工具调用

系统支持多种工具类型，包括：

- `rag_search`：检索企业知识库
- `calculator`：执行计算
- `date_time`：查询时间
- `employee_lookup`：查询员工信息

### 2.3 可观测性

EnterprisePilot 记录执行过程，展示：

- 哪个 Agent 决策了什么
- 调用了哪些工具
- 工具返回了什么结果
- 最终回答如何生成

这使得系统不仅能回答问题，还能解释“为什么这么回答”。

## 3. 适用场景

适合的场景包括：

- 企业内部知识库问答
- 员工信息查询
- 自动化办公助手
- 技术文档检索
- 多步工具协作任务

## 4. 设计原则

- 可追溯：每一步都可以被记录和检查
- 可扩展：新增工具、知识源或 Agent 节点很容易
- 面向企业：强调稳定性、可维护性、审计性
- 可演示：适合展示智能体工作流与工具调用过程

## 5. 关键价值

企业使用 EnterprisePilot 的价值在于：

- 降低知识获取成本
- 提升数据检索效率
- 提高回答的一致性
- 提供更清晰的 Agent 执行解释
- 支持多工具协作任务
