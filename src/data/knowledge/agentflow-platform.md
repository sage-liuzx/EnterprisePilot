# EnterprisePilot 平台说明

## 1. 平台定位

EnterprisePilot 是一个面向企业知识问答和工具协作的智能体平台，体现了“Agent + Tool + RAG + Observability”的组合设计。

## 2. 系统组成

EnterprisePilot 通常由以下模块组成：

- Agent Runtime：负责智能体决策和多步工作流
- RAG Layer：负责知识检索与上下文增强
- Tool Layer：负责计算、时间、查询等工具
- Trace / Evaluation：负责执行过程评估与可观测性
- Frontend：用于展示对话和执行轨迹

## 3. 关键优势

### 3.1 可观测

平台会展示：

- Agent 调用链
- 工具执行过程
- 关键参数
- 步骤状态

### 3.2 可扩展

系统支持：

- 新增工具
- 新增知识库
- 新增智能体节点
- 新增评测规则

### 3.3 适合企业演示

企业场景中，除了“回答问题”，还要看：

- 为什么选这个工具
- 这个问题是否命中知识库
- 执行耗时情况
- 回答质量如何评估

## 4. 典型工作流

一个标准工作流通常为：

1. 用户提问
2. Agent 判断是否需要工具
3. 如果需要，则调用 `rag_search`、`calculator`、`employee_lookup` 等工具
4. 结果返回到 Agent
5. Agent 生成最终回答
6. Trace 与 Evaluation 记录此次执行过程

## 5. 面向的业务场景

适合场景包括：

- 企业知识问答
- 员工信息查询
- 运维说明检索
- 规则说明回答
- 智能协作助手

## 6. 价值体现

EnterprisePilot 不是仅仅让模型“说话”，而是在企业决策、知识管理、任务协作场景中提供一套可控、可解释、可扩展的 Agent 执行框架。
