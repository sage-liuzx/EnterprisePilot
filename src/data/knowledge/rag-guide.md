# RAG 技术说明

## 1. 什么是 RAG

RAG（Retrieval-Augmented Generation，检索增强生成）是一种让大模型在回答问题时先检索外部知识再生成答案的技术。

传统大语言模型依赖训练数据中的参数记忆，而 RAG 可以在推理时补充真实、最新、企业私有的知识，从而提高回答准确性与事实一致性。

## 2. RAG 的核心流程

典型流程如下：

1. 用户提出问题
2. 系统将问题转成向量表示
3. 检索器在知识库中寻找相似文本
4. 召回相关文档片段
5. 将文档片段作为上下文注入大模型
6. 大模型基于上下文生成最终回答

## 3. 为什么企业需要 RAG

企业信息通常存在于：

- 文档
- Wiki
- SOP
- 运营说明
- 会议纪要
- 培训资料

这些内容往往不在模型训练集中，且经常更新。RAG 能让企业智能体在不重新训练模型的情况下，利用最新知识库回答问题。

## 4. EnterprisePilot 中的 RAG 使用方式

在 EnterprisePilot 中，`rag_search` 工具负责：

- 接收用户问题
- 检索知识库中最相关的文档片段
- 返回文本给 Agent
- Agent 再结合用户问题进行最终回答

## 5. 优势

RAG的优势包括：

- 提高事实准确性
- 支持私域知识
- 可更新知识
- 减少幻觉
- 更适合企业知识沟通

## 6. 局限

RAG 也不是万能的：

- 检索质量直接影响回答质量
- 知识库整理不当会导致召回噪音
- 需要清晰的文档结构和分块设计
- 仍需控制上下文长度和成本

## 7. 典型应用案例

- 问公司流程制度
- 问产品功能说明
- 查询内部知识手册
- 基于说明书回答技术问题
- 结合工具完成多步骤任务
